SYSTEM SPECIFICATION & TECHNICAL ARCHITECTURE

          
JobMaker & Job Runner Operating Standard (v3.1.15)

          

            Specification of Python Job Schema v1.0, BEJSON 104a Field Map Cache mandates, AI Plugin Rule Gates, Multi-Page Plan-First Generation, and self-evolving stage runner workflows.
          

        


        

          PART 1: THE NEW OPERATING STANDARD WE'RE SETTING
        


        

          

            1. Python Job Schema v1.0 Parity
            
100% field alignment with Python Joob_Runner.py using explicit columns:

            

              task_id, task_order, task_name, task_description, task_completed, audit_enabled, audit_passed, audit_fail_reason, task_context [], task_reference [], task_mandatory
            

          


          

            2. Field Map Cache Mandate
            
Positional indexing is forbidden. Resolves columns dynamically via field map:

            

              const fieldMap = bejson_core_get_field_map(doc);

              const idx = fieldMap.get("task_context");
            

          


          

            3. Spreadsheet Analogy & Self-Healing
            

              Fields form column headers and Values form data rows. Includes 3-attempt diagnostic feedback loop to self-heal schema errors automatically.
            

          


          

            4. AI Plugin & Extension Rules Gate
            

              True/False gated plugin architecture to passively accept extension rule sets and bind rule directives into AI prompts.
            

          

        


        

          5. Multi-Page Plan-First Website Generation Standard
          
Enforces a 3-phase plan-first generation workflow:

          

            
PHASE 1: MASTER TEMPLATE
Generate master layout template (header, nav links, footer) first.

            
PHASE 2: CHILD PAGES
Derive Index, Feed, Features, About, Contact off master template.

            
PHASE 3: NAV LINK AUDIT
Conclude with Navigation Integrity Audit task verifying 100% route validity.

          

        


        

          PART 2: HOW THE APPLICATION WORKS
        


        

          

            1. Jobs & Registry Hub: Central job storage for loading, saving, and importing BEJSON 104a schemas.
          

          

            2. Self-Evolving Stage Runner: Executes tasks, evaluates AST gates, presents candidate diffs, and commits atomic file swaps.
          

          

            3. AI Job Document Generator: Generates validated BEJSON 104a jobs from prompts with self-healing feedback.
          

          

            4. Dual Ingestion Panels: Context Files (Read-Only study) and Work Attachments (Target files) with ZIP extraction.
          

          

            5. Autonomous System Console: Live action logger tracking all stage evolutions, diffs, API endpoints, and error metrics.
